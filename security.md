# Security Statement

## Intended Users
This repo is used by Michael for the UConn class CSE 3000. It was cloned from
the professor's template and is used to complete assignments that are graded
through Gradescope.

## Risk Assessment
The biggest risk is that people would have access to the material. Since the
repo is public, anyone can see and copy my completed assignments. There are no
passwords, API keys, or personal data in the repo, so the risk is low.

## Steps Taken to Secure the Repo
- I have 2FA turned on for my GitHub account.
- The CODEOWNERS file directs that Matt is the owner. I am the owner of this
  clone for assignments.
- PR reviews make it so work gets a review before being merged to main, so if
  something is bad code, malicious, or would break main, it gets reviewed and
  noted in a safe environment. I am the only one working on this repo, so
  there is no one else to review my PRs and requiring them isn't necessary.
